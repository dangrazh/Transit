Mind Map

User Manual

Mind Map lets you collect ideas and organise them as a tree: one central topic in the middle, with branches and sub-branches around it. The layout arranges itself automatically, and you can move anything by hand whenever you like.

1. Getting started

The first time you open the app you see a small example map. To start your own:

  1. Click Clear and confirm with Delete all.
  2. Type your main topic into the text field at the top and press Enter. This becomes the central topic (the filled bubble in the middle).
  3. Keep typing ideas and pressing Enter – each one is added as a branch of the selected node.

Everything you do is saved automatically in your browser, so the map is still there the next time you open the app on the same computer and browser (see Saving).

2. The screen

  • Toolbar (top): the text field for new ideas and all buttons.
  • Map (middle): your ideas as bubbles connected by lines. The central topic is a filled bubble; each main branch gets its own colour, which all of its sub-ideas share.
  • Hint line (bottom left): shows which node new ideas will be added under, and what will happen while you drag something.
  • Status (bottom right): number of nodes and the current zoom level.

The selected node has a blue outline. Click any node to select it.

3. Adding ideas

To add…Do this
A sub-idea (child)Select the parent node, type the text, press Enter or click Add.
An idea at the same level (sibling)Select a node, type the text, press Shift+Enter or click Add sibling.

After adding, the new node becomes the selected one, so you can keep typing to go deeper. Click a different node first to add somewhere else. The hint line always tells you where the next idea will go (“Adding under: …”).

Adding a sibling to the central topic creates a second, independent central topic. Several topics are arranged in a ring.

4. Renaming and deleting

Rename a node

Double-click it, or select it and press F2 or click Rename. Type the new text, then press Enter (or click elsewhere) to keep it, or Esc to cancel.

Delete a node

Select it and press Delete (or Backspace), or click Delete. Deleting a node also deletes all of its sub-ideas. There is no undo, so export a copy first if you are unsure.

Start over

Clear removes the whole map after asking you to confirm.

5. Moving and re-arranging

Move a node to a different parent

  1. Hold Shift and drag the node onto the node it should belong to.
  2. The target gets a dashed blue ring and the hint line says “Drop to place … under …”.
  3. Let go. The node – together with all of its sub-ideas – now belongs to the new parent and takes on that branch's colour.

Why Shift? Without it, a dragged node pushes other nodes out of its way, so it is hard to land on one. With Shift held, it glides over them. You can press or release Shift at any time during the drag.

You cannot drop a node onto one of its own sub-ideas – that would create a loop, so those nodes are simply not offered as targets.

Tidy up the layout

Re-layout scatters all nodes and lets the map arrange itself afresh. This also releases every pinned node (see next section).

6. Pinning a node in place

Normally the map arranges itself: nodes keep a comfortable distance from each other and stay close to their parent. If you want a node somewhere specific:

  • Drag it to an empty spot and let go. It is pinned there and will not move on its own any more. Pinned nodes show a small blue dot in the top-right corner.
  • Other nodes move out of a pinned node's way, never the other way round.

To release a pinned node, do one of the following:

  • Select it and press P (the same key pins a selected node, too).
  • Drag it back onto its parent (or any other node) – it rejoins the automatic layout there.
  • Click Re-layout to release all pins at once.

A simple click only selects a node; it does not pin it.

7. Zooming and panning

  • Zoom: scroll the mouse wheel over the map. Zooming centres on the mouse pointer.
  • Pan: drag on an empty area of the map.
  • Fit to screen zooms so the whole map is visible, and keeps it fitted while the layout settles. As soon as you zoom, pan or drag yourself, the app stops auto-fitting until you click the button again (or add a new idea).

Long labels are shortened with “…” on screen; the full text is kept and shown when you rename the node.

8. Saving, sharing and images

Automatic saving

Every change is saved straight away in your browser on this computer. Nothing is sent to a server. This means:

  • Your map is not visible to anyone else, and not available on another computer or browser.
  • Clearing your browser data, or using a private window, removes it.
  • The app holds one map at a time. To work on several, export each one to a file.

Export (save to a file)

Export saves the map as a mindmap.json file. Keep it as a backup, store it on a shared drive, or send it to a colleague.

Import (open a file)

Import loads a previously exported .json file. This replaces the map that is currently open – export it first if you want to keep it. Positions and pins are restored exactly as they were.

Picture of the map

PNG saves an image of the whole map (not just the visible part) as mindmap.png, ready to paste into a document, e-mail or presentation.

10. Using the app from SharePoint

When the app is opened directly from a SharePoint document library, SharePoint shows it in a restricted viewer that does not allow downloads. The app notices this and adapts:

  • Export shows the map as text. Click Copy, paste it into Notepad and save the file with a .json ending. You can also try Try download.
  • Import lets you either choose a file or paste exported text into the box and click Load.
  • PNG shows the image. Right-click it and choose “Save image as…” or “Copy image”.
The SharePoint viewer may also not keep your map between visits. Export before closing it. If your organisation provides a direct web link to the app, prefer that – everything works normally there.

11. Tips and troubleshooting

My new idea was added in the wrong place.

It goes under the selected node (shown in the hint line). Hold Shift and drag it onto the right parent, or delete it, select the correct parent and add it again.

I can't drop a node onto another one – the target moves away.

Hold Shift while dragging.

A node won't move back into the layout.

It is pinned (blue dot). Select it and press P, or click Re-layout.

Pressing Delete or P does nothing.

The cursor is probably still in the text field at the top. Click on the map, then try again.

My map is gone.

Maps are stored per browser. Check that you are using the same computer and browser, and not a private window. If browser data was cleared, import your last exported file. Export regularly to be safe.

The map is too big to see.

Click Fit to screen.
